# Retail Sales Forecasting Platform

## Overview

An end-to-end Data Science and Data Engineering project that predicts future retail sales using statistical modeling and machine learning.

## Features

- ETL Pipeline
- PostgreSQL Database
- Statistical Analysis
- Sales Forecasting
- FastAPI Backend
- Streamlit Dashboard
- Docker Deployment

## Tech Stack

- Python
- PostgreSQL
- Pandas
- Scikit-learn
- FastAPI
- Streamlit
- Docker
